Math Logic Learning & Solver — Pastel Blue Edition

ไฟล์ในชุดนี้:
- app.py: เว็บแอป Streamlit พร้อมบทเรียน 6 บท เมนูย่อย และเครื่องมือ
- requirements.txt: ไลบรารีที่ต้องติดตั้ง

การรันในเครื่อง:
1. ติดตั้ง Python
2. เปิด Terminal ในโฟลเดอร์นี้
3. รัน: pip install -r requirements.txt
4. รัน: streamlit run app.py

การเผยแพร่บน Streamlit Community Cloud:
1. อัปโหลด app.py และ requirements.txt เข้า GitHub repository
2. ใน Streamlit Community Cloud เลือก repository และไฟล์ app.py
3. Deploy app

หมายเหตุ: เครื่องมือคำนวณสูตรรองรับตัวแปรประพจน์ เช่น p, q, r และตัวเชื่อม ¬ ∧ ∨ → ↔
ตัวบ่งปริมาณ (∀, ∃) มีเนื้อหาในบทเรียน แต่ยังไม่ได้รวมตัวแปลสูตรตัวบ่งปริมาณเข้ากับเครื่องคำนวณค่าความจริง
